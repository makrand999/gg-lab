Zone A • Coordinate Datum • Ground Line XY

Monge Ground Line & Dihedral Hinge Unfolding

PLATE A-1 • DIHEDRAL HINGE PROJ: 1:1

fig. A1 — unfolding the dihedral angle into a coplanar Monge sheet

90° FOLDED 180° FLAT MONGE SHEET

In first-angle projection, space is framed by the Vertical Plane (VP) and Horizontal Plane (HP) intersecting at the Ground Line XY (Y = 0). To produce a 2D sheet, the 3D horizontal plane is hinged downward by 90°.

Above XY — Vertical Plane (VP / Elevation) Contains height (Z) and width (X). Points carry prime ticks (a', b').
Below XY — Horizontal Plane (HP / Plan View) Contains depth (Y) and width (X). Points are lowercase plain (a, b).
• Alex's note: Elevation looks forward (Z + X), while Plan looks straight down (Y + X). XY line is the physical hinge axis.

Zone B • Projector Invariant • Snapping Detent

Vertical Projector Rays & Coordinate Snapping

PLATE B-1 • MAGNETIC DETENT SIMULATOR DETENT: 14PX

fig. B1 — vertical projector ray and magnetic capture detent

[MOVE CURSOR OVER PLATE TO TEST MAGNETIC LOCK]

In Monge geometry, an elevation point (a') and its corresponding plan point (a) must share the same horizontal coordinate (X). EduCAD contains a built-in magnetic snap solver that enforces this geometric constraint.

Projector Invariant: X(a') ≡ X(a) Moving down from the VP activates a dashed alignment ray (BIS Type B/G).
Hysteresis Detent Threshold When within 14px of the ray, the cursor locks magnetically to guarantee zero coordinate drift.
• Snapping Invariant: If X(a') != X(a), the drawing violates Euclidean orthographic projection! Always snap to the projector ray.

Zone C • Line Rotation • True Length

The Rotating Line Solver & Horizontal Loci

PLATE C-1 • ROTATING LINE SOLVER TL=80MM

fig. C1 — rabattement rotation solver revealing true geometric length

INCLINATION θ 30°

An inclined line exhibits foreshortening in both views: its elevation length is TL · cos φ and its plan length is TL · cos θ. To find True Length without trigonometry, Monge rotated the line into a principal plane.

Rabattement Arc Swinging endpoint b' onto the horizon of a' produces a projection whose conjugate view displays pure True Length (TL).
Invariant Loci Horizontal dashed lines define constant boundary loci that endpoints cannot exceed.
• Rabattement Secret: Swing B until it reaches the horizontal level of A. The line is now parallel to VP, so elevation displays pure True Length directly!

Zone D • Multi-View • 45° Miter Depth Transfer

Multi-View Projection & 45° Depth Transfer

PLATE D-1 • THREE-VIEW ALIGNMENT FIRST ANGLE • 1:1

fig. D1 — orthographic 3-view correspondence with 45° depth transfer

[ANIMATED RAYS REFLECT PLAN DEPTH AUTOMATICALLY TO PROFILE]

To define 3D solids unambiguously, first-angle projection lays out three views: Elevation (Front), Plan (Top), and Profile (Side). Depths from the plan view transfer to the profile view using a 45° miter reflection line.

45° Miter Reflection Line Turns horizontal plan projectors into vertical profile projectors instantly in the fourth quadrant.
Line Type Standards Visible outlines: Continuous thick (Code A). Hidden internal edges: Dashed medium (Code E).
• Draftsman's Miter Shortcut: No compass needed! Draw a 45° line from the origin (XY/YZ). Any plan depth shot rightward reflects upward at 90°.
